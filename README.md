# Quiz Generator Toolkit

Инструмент для генерации тестов для **iSpring Quiz** из Word-файлов.

Проект содержит два режима работы:

- ✅ **generator_xlsx.py** — генерирует Excel-файл для импорта в iSpring (стабильно работает, рекомендуется)
- ⚠ **generator_quiz.py** — генерирует готовый `.quiz` файл напрямую (экспериментальный режим, возможны ошибки, но меньше действий и быстрее)

# Installation

## Requirements

- Python 3.10+
- Интернет для установки зависимостей

---

## Windows

1. Установить Python  
   https://www.python.org/downloads/

   ⚠️ При установке обязательно поставить галочку **Add Python to PATH**

2. Скачать проект (ZIP) и распаковать

3. Открыть терминал в папке проекта  
   В адресной строке проводника написать:

cmd

4. Установить зависимости:

pip install -r requirements.txt

Если не работает:

python -m pip install -r requirements.txt

5. Запустить генератор:

python generator_xlsx.py

или

python generator_quiz.py

---

## macOS / Linux

1. Проверить Python:

python3 –version

2. Перейти в папку проекта:

cd путь/к/папке/проекта

3. Установить зависимости:

pip3 install -r requirements.txt

4. Запустить:

python3 generator_xlsx.py

или

python3 generator_quiz.py

# Usage

## generator_xlsx.py (Рекомендуемый способ)

Генерирует Excel-файл для импорта в iSpring Quiz.

✔ Стабильная работа  
✔ Минимальный риск ошибок  

После генерации импортируйте файл в iSpring через:

Import Questions → Excel

---

## generator_quiz.py (Экспериментальный режим)

Генерирует готовый `.quiz` файл напрямую.

⚠ Возможны структурные ошибки, обязательно проверяйте выходной тест вручную!  

---

# Configuration

Для работы **generator_quiz.py** требуется папка:

ready_example/

В ней должны находиться:

- document.json  
- metainfo.json  
- workspace.json  
- папка Themes  
- файл темы `.qthm`  

Это эталонный шаблон теста, который используется как база для генерации.

# Word File Format Requirements

⚠ Программа работает только с таблицами в формате `.docx`.

Если структура будет нарушена — импорт может работать некорректно.

---

## Структура таблицы

Минимум 5 столбцов:

| № | Любой столбец | Текст вопроса | Варианты ответов | Правильные ответы |

Используются:

- 3 столбец (индекс 2) → Текст вопроса  
- 4 столбец (индекс 3) → Варианты ответов  
- 5 столбец (индекс 4) → Правильные ответы  

Первая строка — заголовок (игнорируется).

---

## Формат закрытых вопросов (MC / MR)

Каждый вариант должен быть с новой строки:

А) Текст ответа
Б) Текст ответа
В) Текст ответа
Г) Текст ответа

Обязательно:

- Буква
- )
- Пробел
- Текст ответа

---

## Формат правильных ответов

### Один правильный ответ:

А

### Несколько правильных ответов:

А, В

⚠ Разделитель — строго `", "` (запятая + пробел)

---

## Числовые ответы

Если ответы содержат числа с запятой:

Правильно:

0,6, 1,2

Неправильно:

0,6,1,2

---

## Открытые вопросы (TI)

Если столбец "Варианты ответов" пуст — вопрос считается открытым.

Ответы перечисляются через:

ответ1, ответ2

или

ответ1; ответ2

---

## Общие ограничения

- Файл должен быть `.docx`
- Вопросы должны быть в таблице
- Пустые строки недопустимы
- Максимум 10 вариантов ответа
- Максимум 10 правильных ответов
