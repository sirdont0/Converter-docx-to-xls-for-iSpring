# Формат Word-файла (обязательно к соблюдению)

Программа работает только с таблицами в формате `.docx`.  
Если структура таблицы будет отличаться — импорт может работать некорректно.

---

## Структура таблицы в Word

Таблица должна содержать **минимум 5 столбцов**:

| № | Любой столбец | Текст вопроса | Варианты ответов | Правильные ответы |

⚠️ ВАЖНО:  
Программа использует:

- **3 столбец (индекс 2)** → Текст вопроса  
- **4 столбец (индекс 3)** → Варианты ответов  
- **5 столбец (индекс 4)** → Правильные ответы  

Первые два столбца могут быть любыми (номер, тема и т.д.).

---

## Формат закрытых вопросов (MC / MR)

### В столбце "Варианты ответов":

Каждый вариант должен быть с новой строки в формате:

А) Текст ответа  
Б) Текст ответа  
В) Текст ответа  
Г) Текст ответа  
Д) Текст ответа  

⚠️ Обязательно:
- Буква
- Закрывающая скобка `)`
- Пробел
- Текст ответа

Пример:

А) Москва  
Б) Париж  
В) Берлин  
Г) Рим  

---

## Формат правильных ответов (закрытые вопросы)

В столбце "Правильные ответы":

### Если один правильный ответ:

А

### Если несколько правильных ответов (MR):

Разделять **строго запятая + пробел**

Правильно:

А, В

Неправильно:

А,В
А;В
А , В

⚠️ Разделитель — только `", "` (запятая и пробел)

---

## Если правильные ответы — числа

Если ответы числовые с запятой:

Правильно:

0,6, 1,2

(разделение между ответами — запятая + пробел)

Неправильно:

0,6,1,2

Иначе программа разобьёт число неправильно.

---

## Формат открытых вопросов (TI)

Если в столбце "Варианты ответов" ПУСТО,
то вопрос автоматически считается открытым.

В столбце "Правильные ответы":

Ответы перечисляются через:

ответ1, ответ2

или

ответ1; ответ2

⚠️ Также обязательно разделять через `", "` или `"; "` (с пробелом).

---

## Общие требования

- Файл должен быть в формате `.docx`
- Вопросы должны быть в таблице
- Первая строка таблицы — заголовок (она игнорируется)
- Пустые строки в таблице недопустимы
- Максимум 10 вариантов ответа
- Максимум 10 правильных ответов для открытых вопросов

# Установка и запуск

## Требования

- Python 3.10 или новее
- Интернет для установки зависимостей

---

# Windows

## 1. Установить Python

Скачать Python:

https://www.python.org/downloads/

⚠️ При установке обязательно поставить галочку:

Add Python to PATH

---

## 2. Скачать проект

- Скачать ZIP с GitHub
- Распаковать в любую папку

---

## 3. Открыть терминал в папке проекта

Открыть папку проекта  
В адресной строке проводника написать:

cmd

и нажать Enter

---

## 4. Установить зависимости

pip install -r requirements.txt

Если не работает:

python -m pip install -r requirements.txt

---

## 5. Запустить программу

python main.py

---

# macOS / Linux

## 1. Проверить Python

Открыть Terminal и выполнить:

python3 --version

Если Python отсутствует — установить с python.org

---

## 2. Перейти в папку проекта

cd путь/к/папке/проекта

---

## 3. Установить зависимости

pip3 install -r requirements.txt

Если не работает:

python3 -m pip install -r requirements.txt

---

## 4. Запустить программу

python3 main.py
